Why we're different

Free hosting and self-hosting

Use the public instance or run GuestPass on your own server.

Public hosting

Free access without ads

The public instance is free and has no ads or paid feature tiers. GuestPass runs the room coordination and database on the server. Participants send media between browsers.

Source-available · UEL v1.0

Read the code. Run the code. Keep it open.

GuestPass uses the UEL v1.0 license. You can read the source, modify it, and self-host it under the license terms. If you distribute a modified version, those terms require sharing its source.

P2P mesh

Your media goes browser-to-browser. We can't watch it.

Browsers exchange encrypted camera and microphone media. A configured TURN relay can forward encrypted packets without decoding them. The GuestPass application server handles signaling and connection metadata. It does not receive media.

Privacy

Data and retention

GuestPass stores host identities, streams, invitations, session records, and abuse reports. It does not record media or save chat. Under the default retention settings, invitation names and emails are deleted within 24 hours of stream end. Session records and abuse reports have separate retention rules. Participants can record media or copy chat themselves.

Guest and broadcast controls

GuestPass uses WebRTC for browser-to-browser media. The server manages invitations, room coordination, and signaling.

Zero-signup guests

Guests join from a browser tab with a magic link. No account, no install, works on a borrowed laptop.

Individual OBS sources

Assign each guest to a browser source and arrange those sources in OBS.

Screen-sharing permission

Enable screen sharing for a guest when needed. You can revoke permission during the stream.

Optional TURN relay

GuestPass uses direct peer connections by default. Configure a TURN relay for networks that block those connections.

Stream quality limits

Set maximum resolution, frame rate, and bitrate for each stream to reduce bandwidth and CPU use.

Source access

Use the free public instance at guest-pass.link, or self-host the same binary. You can read and modify the source under UEL v1.0.
